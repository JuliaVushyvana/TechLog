# TeachLog

TeachLog — застосунок, який допомагає викладачам у роботі та полегшує щоденну рутину. У ньому можна скласти розклад занять, вести список учнів і записувати деталі кожного уроку: тему, що робили, результати тренажерів. На основі цих записів AI за кілька секунд генерує фідбек для батьків, що економить викладачеві багато часу.

Кросплатформний застосунок на Flutter (Dart): один код запускається на Android, iOS, Web, macOS, Windows та Linux.

## Можливості

- **Головна** — заняття на сьогодні, учні без проведених занять понад 2 тижні.
- **Розклад** — календар на місяць, постійний розклад учнів (день тижня + час), автоматичне заповнення місяця, разові заняття та відпрацювання.
- **Уроки** — статуси «заплановано / проведено / скасовано / відпрацювання», тема, опис і активності кожного заняття.
- **Учні** — ім'я та прізвище, вік, напрями, рівень, контакт батьків, нотатки, позначка інклюзії, архів.
- **Тренажери** — фіксація результатів (флешкарти, стовпці, ментальна арифметика, таблиця Шульте, «Знайди кіберкішку», «Знайди пару») з налаштуваннями, найкращим часом і графіком прогресу.
- **AI-фідбек** — генерація щомісячного відгуку для батьків через Gemini з урахуванням уроків і результатів учня. Можна обрати тон, обсяг, мову, підпис і власні побажання до стилю. Готовий текст можна відредагувати й надіслати через «Поділитися».
- **Налаштування** — профіль і грейд, постійний розклад, учні, типи занять.
- Світла й темна тема (за налаштуванням системи).

## Обліковий запис і дані

- Екрани реєстрації, входу та видалення облікового запису.
- Дані зберігаються у файлах на пристрої (`shared_preferences`), окремо для кожного вчителя. Паролі зберігаються лише у вигляді солоного хешу SHA-256.
- Після закриття застосунку дані та вхід зберігаються. Дані не синхронізуються між пристроями: на кожному телефоні, комп'ютері чи в браузері вони свої.
- Видалення облікового запису стирає всі дані цього вчителя.
- Для конфіденційності в AI передається лише ім'я учня, без прізвища та контактів батьків.

## Оформлення

- Власна іконка застосунку на всіх платформах (адаптивна на Android).
- Splash screen: системний (з підтримкою Android 12+, темної теми та web) та анімований у застосунку.

## Підключення AI

AI-фідбек використовує безкоштовний рівень Gemini API:

1. Отримайте ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. У застосунку: вкладка **«Фідбеки»** → картка **«Налаштування фідбеку»** → поле **«Ключ Gemini API»**.

Ключ зберігається лише на пристрої і не потрапляє в репозиторій.

## Запуск

```bash
flutter pub get
flutter run              # на підключеному телефоні чи емуляторі
flutter run -d chrome    # у браузері
flutter run -d macos     # на Mac (windows / linux — на відповідних системах)
```

Тести:

```bash
flutter test
```

У debug-збірці на екрані входу є кнопка «Демо-акаунт з тестовими даними» для швидкого ознайомлення.

## Технології

Flutter, Riverpod, go_router, shared_preferences, fl_chart, share_plus, Gemini API.
